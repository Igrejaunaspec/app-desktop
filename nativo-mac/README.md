# Igreja UNASP EC — app nativo para Mac

App nativo (SwiftUI) do APP IGREJA UNASP EC. Usa o mesmo banco e as mesmas regras de segurança do site.
Não guarda senhas em arquivo: o login fica no Chaveiro do macOS.

Baixar: veja **Releases** ao lado. Depois de arrastar para Aplicativos, rode uma vez no Terminal:
`xattr -cr "/Applications/Igreja UNASP EC.app"`
